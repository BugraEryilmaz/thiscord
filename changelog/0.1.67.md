## Highlights

- **Steadier chat scrolling.** The message list now uses the app window's own scrolling instead of a custom one. Scrolling no longer shifts while messages appear, and the message you are reading stays in place when older messages load above it.

## Improved

- Images in chat load as you scroll near them, and each one downloads only once instead of again every time it comes back into view.
- Jumping to a replied-to message or a search result now places it in the middle of the chat.
