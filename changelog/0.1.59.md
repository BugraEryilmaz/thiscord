## Highlights

- **Choose your navigation shortcuts.** The quick switcher, search, shortcut reference and channel, unread and server jumps can now be rebound in Settings → Shortcuts & overlay, just like the voice keys.
- **The shortcut reference shows your keys.** Ctrl+/ lists the keys you actually chose, so it stays correct after you rebind something.

## New

- Record a navigation shortcut by clicking it and pressing the keys. Today's keys are the defaults, and Reset brings them back.
- Clearing a navigation shortcut turns that command off on this device.

## Improved

- Shortcuts are saved per device and must use Ctrl, Alt or Super, or a function key, so typing and list navigation keep working.
- A shortcut can no longer repeat another navigation, voice or overlay key on the same device.
- Keys that menus, lists and the message box depend on (Esc, Enter, arrows, Shift+F10 and ↑ to edit) are listed under **Fixed keys**.
